# Arena contracts

Foundry project for the social trading arena: `AgentRegistry`, `StrategyMarketplace`, `PerformanceRegistry`,
`AgentTreasury`, `RiskOracle`. Chainlink CRE writes signed reports to `PerformanceRegistry` and `RiskOracle`
through the CRE forwarder. Target chains: Base Sepolia (testnet) and Base (mainnet).

## Setup

```bash
cd contracts
forge install foundry-rs/forge-std --no-git   # only needed on a fresh clone; lib/ is git-ignored
forge build
```

Solidity 0.8.24, `evm_version = cancun`, optimizer on.

## Test

```bash
forge test -vv
```

## Export ABIs

```bash
./export-abis.sh   # runs forge build, writes abi/<Contract>.json (requires jq)
```

## Deploy

Configuration is read from environment variables. The signer is passed on the command line, never stored here.

| Env var | Meaning |
|---|---|
| `USDC_ADDRESS` | USDC token. Base Sepolia: `0x036CbD53842c5426634e7929541eC2318f3dCF7e`. Base: `0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913`. Confirm on BaseScan. |
| `CRE_FORWARDER` | Chainlink CRE forwarder for the target chain (or the CRE mock forwarder during simulation). |
| `RELAYER_ADDRESS` | Conversion relayer that receives top-ups for 0G credit. |
| `PLATFORM_TREASURY` | Address that receives the platform share of fork fees. |
| `PLATFORM_BPS` | Platform share of fork fees in bps. Default `3000`. |
| `DEFAULT_DAILY_TOPUP_CAP_USD6` | Per-agent daily top-up cap, 6 decimals. Default `2000000` (2 USDC). |
| `RESERVE_FLOOR_USD6` | Minimum reserve every agent keeps in its treasury. Default `0`. |
| `BASE_SEPOLIA_RPC_URL` / `BASE_RPC_URL` | RPC endpoints used by `--rpc-url base_sepolia` / `base`. |
| `BASESCAN_API_KEY` | BaseScan key used by `--verify`. |

Deploy to Base Sepolia (signer from a Foundry keystore account):

```bash
forge script script/Deploy.s.sol --rpc-url base_sepolia --account <keystore-name> --broadcast --verify -vvvv
```

Deploy to Base mainnet: same command with `--rpc-url base`. Use a funded signer and double-check every env var first.

Dry run without broadcasting (simulation only):

```bash
forge script script/Deploy.s.sol --rpc-url base_sepolia
```

## Verify

`--verify` during deploy verifies each contract. To verify one manually:

```bash
forge verify-contract <address> src/PerformanceRegistry.sol:PerformanceRegistry \
  --chain base_sepolia --constructor-args $(cast abi-encode "constructor(address)" $CRE_FORWARDER)
```

## Where the addresses go

The deploy script prints every address. Copy them as follows:

| Contract | Goes to |
|---|---|
| `AgentRegistry` | app/worker config as the registry address |
| `StrategyMarketplace` | app/worker config as the marketplace address |
| `PerformanceRegistry` | CRE WF1 receiver config, and app/worker config |
| `AgentTreasury` | app/worker config as the treasury address |
| `RiskOracle` | CRE WF2 receiver config, and the risk banner in the app |
| `RELAYER_ADDRESS` | the relayer key pair the worker uses to convert USDC into 0G credit |
| `CRE_FORWARDER` | taken from Chainlink CRE docs for the chain, not generated by this repo |
